# WebSerial bright palette iteration

Classification: DEVELOPMENT appearance and packaging review, 2026-09-10.

[Board + card overview](webserial-overview.png) · [Board comparison](board-comparison.png) · [Review](review.html).

Uses exact accent colors from the [live PulseSensor WebSerial example](https://worldfamouselectronics.github.io/PulseSensorPlayground/webserial-explainer/), linked by the [PulseSensor WebSerial guide](https://pulsesensor.com/pages/pulsesensor-and-webserial).

| Board/card area | Color | WebSerial source role |
| --- | --- | --- |
| LED | #FF6B6B coral | Signal, heart and buttons |
| Sense | #44FF44 lime | BPM and live data |
| Filter | #51CF66 green | Connected indicator |
| Amp / gain | #64C8FF sky blue | Beat value |
| Bias | #FFAA44 orange | IBI and method highlights |
| Power | #CCCCCC gray | Method text |

These are visual palette assignments, not equivalences between physical circuit stages and dashboard measurements. Black labels, white page backgrounds, existing dotted board boundaries and the full continuous schematic layout remain unchanged.
